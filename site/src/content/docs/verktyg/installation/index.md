# Installation

För att komma igång med C# behöver du installera några program. Här är vad du behöver, i den ordning det är lämpligt att installera dem:

1. [.NET SDK](https://dotnet.microsoft.com/download) — själva verktygen som kompilerar och kör C#-kod. Behövs alltid, oavsett vilken editor du väljer nedan (Visual Studio installerar den ofta automatiskt, men VS Code och Rider kräver att du installerar den separat).
2. [Git](Gitinstallation.md) — versionshantering, behövs oavsett vilken editor du väljer
3. En kodeditor — välj **en** av:
   - [Visual Studio Code](VSCodeinstallation.md) — lättvikt, gratis, populär
   - [Visual Studio](VisualStudioinstallation.md) — Microsofts fullständiga IDE, kraftfull debugger
   - [JetBrains Rider](Riderinstallation.md) — JetBrains IDE, gratis för studerande

Genom att installera och använda dessa program kommer du vara redo att börja lära dig och utveckla med C# och dra nytta av dess möjligheter inom mjukvaruutveckling.
