# Prompting

En prompt är instruktionen du skickar till ett AI. Kvaliteten på prompten avgör kvaliteten på svaret. Prompting är en professionell skill — inte magin det verkar som, utan ett hantverk med tydliga principer.

## Grundregeln

> Ge AI den kontext en duktig juniorutvecklare skulle behöva för att lösa uppgiften åt dig.

Otydliga prompts ger vaga svar. Konkreta prompts ger användbara svar.

## De viktigaste teknikerna

| Teknik | Kort beskrivning |
|--------|-----------------|
| Rollen | Säg vad AI:t är: "Du är en erfaren C#-arkitekt" |
| Kontexten | Ge bakgrund: "Vi använder .NET 8, Clean Architecture" |
| Uppgiften | Var precis: "Skriv en generic repository för EF Core" |
| Formatet | Specificera output: "Svara med C#-kod + kort förklaring" |
| Begränsningarna | "Inga externa bibliotek, inga kommentarer på engelska" |

## Vad du hittar i detta avsnitt

- **Grunderna** — struktur, roller, exempel
- **Tekniker** — chain-of-thought, few-shot, system prompts
