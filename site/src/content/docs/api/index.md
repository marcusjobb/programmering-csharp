# APIer

Ett API (Application Programming Interface) är ett gränssnitt som låter din applikation prata med andra applikationer — eller låter andra prata med din.

I det här avsnittet lär du dig hur man bygger och dokumenterar ett REST API i .NET med moderna verktyg.
