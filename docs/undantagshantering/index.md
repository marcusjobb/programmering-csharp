# Undantagshantering

Kod kan misslyckas av skäl du inte kan förutse vid kompilering — en fil finns inte, ett nätverksanrop timeout:ar, en användare skriver in text där du väntade dig ett tal. Undantagshantering (exception handling) är hur C# låter dig fånga sånt och hantera det, istället för att programmet bara kraschar.
