## Datatyper

| Ord | Förklaring |
| --- | --- |
| bool | Rymmer exakt två värden: `true` eller `false`. |
| byte | Den minsta vanliga heltalstypen. Rymmer 0 till 255. |
| char | Ett enda tecken, skrivet inom enkla citattecken: `'A'`. |
| decimal | Flyttal byggt för pengar och exakta beräkningar — ingen avrundningsknöl som `double`. Skrivs med `m`, t.ex. `19.99m`. |
| double | Standardflyttalet i C#, med cirka 15-17 siffrors precision. |
| float | Flyttal med cirka 6-7 siffrors precision. Skrivs med `f` efter talet, t.ex. `3.14f`. |
| int | Standardheltalet i C#. Rymmer -2 147 483 648 till 2 147 483 647 — räcker för nästan allt. |
| long | Heltal för mycket stora tal, när `int` inte räcker till. |
| short | Heltal från -32 768 till 32 767. |
| string | Text — en ordnad sekvens av `char`, skriven inom dubbla citattecken. |
