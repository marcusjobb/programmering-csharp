## Programmeringsspråk

| Ord | Förklaring |
| --- | --- |
| Angular | Ett webbramverk (TypeScript) från Google för att bygga interaktiva webbapplikationer. |
| Composer | PHP:s pakethanterare — hanterar bibliotek och beroenden i PHP-projekt. |
| CSS | Cascading Style Sheets. Språket som stylar HTML — färger, layout, typsnitt. |
| Docker | Ett program som paketerar en app och dess beroenden i en isolerad container, så den kör likadant överallt. |
| Docker Compose | Definierar och kör flera Docker-containers tillsammans via en YAML-fil, på en och samma dator. |
| Docker Desktop | Det grafiska programmet som kör Docker på Windows/Mac, med GUI och inbyggd Kubernetes. |
| Docker Hub | Ett molnbaserat register där färdiga Docker-images laddas upp och delas offentligt. |
| Docker Machine | Äldre verktyg för att skapa och hantera Docker-värdar (virtuella maskiner) lokalt eller i molnet. |
| Docker Registry | Ett självhostat förråd för att lagra och distribuera Docker-images — motsvarande Docker Hub fast privat. |
| Docker Swarm | Dockers inbyggda klustringsverktyg för att köra containers över flera servrar samtidigt. |
| Docker Toolbox | Föregångaren till Docker Desktop, för äldre Windows/Mac-versioner utan inbyggt containerstöd. |
| Gatsby | Ett statiskt webbplatsbyggverktyg baserat på React och GraphQL. |
| Git | Ett versionshanteringssystem som håller koll på ändringar i kod över tid. |
| GitHub | En molntjänst för att hosta Git-repon, med samarbetsverktyg som pull requests och issues. |
| GitLab | En konkurrent till GitHub — molntjänst för Git-repon med inbyggd CI/CD. |
| HTML | Hypertext Markup Language. Språket som strukturerar innehållet på en webbsida. |
| Hugo | Ett mycket snabbt statiskt webbplatsbyggverktyg skrivet i Go. |
| JavaScript | Programmeringsspråket som körs i webbläsaren och gör webbsidor interaktiva. |
| Jekyll | Ett statiskt webbplatsbyggverktyg skrivet i Ruby — används bland annat av GitHub Pages. |
| JSON | JavaScript Object Notation. Ett textformat för att strukturera data i nyckel-värde-par. |
| Markdown | Ett lättviktigt textformat för att formatera text med vanliga tecken, t.ex. `#` för rubriker. |
| Node | En körmiljö (Node.js) som låter JavaScript köras utanför webbläsaren, t.ex. på en server. |
| NPM | Node Package Manager. Pakethanteraren för JavaScript/Node-projekt. |
| PHP | Ett serverside-programmeringsspråk, vanligt för webbutveckling (t.ex. WordPress). |
| React | Ett JavaScript-bibliotek från Meta för att bygga användargränssnitt med komponenter. |
| SQL | Structured Query Language. Språket för att hämta och ändra data i en relationsdatabas. |
| Vue | Ett JavaScript-ramverk för att bygga användargränssnitt, känt för sin enkla inlärningskurva. |
| XML | Extensible Markup Language. Ett märkspråk för att strukturera data, mer strikt än HTML. |
| YAML | "YAML Ain't Markup Language" (självrefererande akronym). Ett läsbart textformat för konfiguration, t.ex. i Docker Compose. |
| Yarn | Ett alternativ till NPM för att hantera JavaScript-paket och beroenden. |
