## IT Yrken

| Ord | Förklaring |
| --- | --- |
| Backend | Logiken bakom ett program — det som körs på servern, dolt för användaren. |
| Backend utvecklare | Bygger och underhåller serverlogik, databaser och API:er — det som händer bakom kulisserna. |
| CEO | Verkställande direktör (VD) — högsta chefen i ett företag, ansvarar för övergripande strategi och resultat. |
| Cloud | En molntjänst — datorkraft, lagring och tjänster som körs hos en leverantör istället för på egen hårdvara. |
| Cloud Architect | Designar den övergripande molnarkitekturen för en organisation — vilka tjänster som används och hur de hänger ihop. |
| Cloud Consultant | Rådgivare som hjälper kunder välja molnstrategi och leverantör, ofta utan att själv bygga lösningen. |
| Cloud Engineer | Bygger och underhåller molninfrastrukturen själv — IaC, pipelines, drift. |
| Cloud Security | Fokuserar specifikt på säkerhet i molnmiljöer — åtkomstkontroll, kryptering, regelefterlevnad. |
| Cloud utvecklare | Utvecklar applikationer byggda för att köras i molnet, t.ex. serverless-funktioner. |
| DevOps | En kultur och arbetssätt som kombinerar utveckling och drift för snabbare, mer pålitliga releaser. |
| DevOps Architect | Designar CI/CD-pipelines och verktygskedjor för en hel organisation. |
| DevOps Consultant | Rådgivare som hjälper team införa DevOps-arbetssätt, ofta utan att själv implementera det. |
| DevOps Engineer | Bygger och underhåller CI/CD-pipelines, automatisering och driftmiljöer i det dagliga arbetet. |
| Frontend | Det som användaren ser. Användargränssnittet. |
| Frontend utvecklare | Bygger användargränssnitt — det som användaren interagerar med direkt i webbläsaren eller appen. |
| Fullstack | En person som kan utveckla både frontend och backend. |
| Intern | Engelska motsvarigheten till praktikant — vanligt i internationella och amerikanska bolag. Se även LIA, Praktikant. |
| IT | Informationsteknik. |
| IT-arkitekt | Planerar den tekniska helhetslösningen för ett IT-system — vilka komponenter som ingår och hur de kommunicerar. |
| IT-konsult | Rådgivare som hjälper företag lösa specifika IT-problem, ofta tidsbegränsat och externt. Se även Konsult. |
| IT-säkerhet | Skyddar system och data mot intrång, dataförlust och missbruk. |
| IT-support | Löser vardagliga tekniska problem för användare — inloggning, hårdvara, mjukvara. |
| IT-tekniker | Installerar, underhåller och reparerar hårdvara och nätverk på plats. |
| Konsult | En anställd hos ett konsultbolag som hyrs ut för att arbeta hos kundföretag, ofta specialist inom ett område. Se även IT-konsult, Underkonsult. |
| Konsultchef | Chef över konsulter på ett konsultbolag — ansvarar för bemanning, kundrelationer och konsulternas karriärutveckling. Leder inte konsultens dagliga arbete hos kund. |
| LIA | Lärande i arbete — yrkeshögskolans obligatoriska praktikperiod, en del av utbildningen som ger högskolepoäng. Se även Praktikant, Intern. |
| Praktikant | En person som gör praktik hos ett företag för att lära sig yrket, ofta som del av en utbildning. Se även LIA, Intern. |
| Product Owner | Äger produktens backlog och prioriterar vad teamet ska bygga härnäst, utifrån affärsvärde och kundbehov. |
| Scrum Master | Faciliterar Scrum-processen i ett agilt team — håller i ceremonier och undanröjer hinder för teamet. Inte en chef över teamet. |
| Systemarkitekt | Planerar hur ett helt system ska vara uppbyggt — struktur, komponenter och hur de samverkar. |
| Systemutvecklare | Skriver och underhåller kod för affärssystem, ofta i en specifik organisation snarare än på konsultuppdrag. |
| Underkonsult | En konsult som hyrs in via ett annat konsultbolag snarare än direkt av kundens konsultbolag — en mellanhand i uppdraget. Se även Konsult. |
