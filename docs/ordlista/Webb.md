## Webb

| Ord | Förklaring |
| --- | --- |
| CDN | Content Delivery Network — ett nätverk av servrar utspridda geografiskt som levererar webbinnehåll från servern närmast användaren, för snabbare laddtider. |
| DNS | Domain Name System — översätter domännamn (t.ex. `google.com`) till IP-adresser så webbläsaren hittar rätt server. |
| FTP | File Transfer Protocol — överför filer mellan datorer över ett nätverk, okrypterat. |
| FTPS | FTP Secure — FTP med krypterad anslutning (SSL/TLS) ovanpå. |
| HTTP | Hypertext Transfer Protocol — protokollet webbläsare använder för att hämta webbsidor från servrar, okrypterat. |
| HTTPS | HTTP Secure — HTTP krypterat med TLS. Standarden för alla moderna webbplatser. |
| IMAP | Internet Message Access Protocol — hämtar e-post från en server men låter meddelandena ligga kvar där, synkade mellan flera enheter. |
| IP | Internet Protocol — adresseringssystemet som ger varje enhet på ett nätverk en unik adress. |
| POP | Post Office Protocol — hämtar e-post från en server och laddar vanligtvis ner den till en enhet. Äldre standard än IMAP. |
| SFTP | SSH File Transfer Protocol — filöverföring över en krypterad SSH-anslutning. Säkrare efterföljare till FTP. |
| SMTP | Simple Mail Transfer Protocol — skickar e-post från avsändare till mottagarens mejlserver. |
| SSH | Secure Shell — ett krypterat protokoll för att fjärransluta till och styra en annan dator via terminalen. |
| SSL | Secure Sockets Layer — äldre krypteringsprotokoll för säker datatrafik online. Föregångare till TLS. |
| TLS | Transport Layer Security — dagens krypteringsstandard för säker datatrafik, efterträdare till SSL. |
| URL | Uniform Resource Locator — adressen som pekar ut en specifik resurs på webben, t.ex. en sida eller fil. |
| VPN | Virtual Private Network — skapar en krypterad tunnel mellan din enhet och ett nätverk, döljer trafik och plats. |
| VPS | Virtual Private Server — en virtuell server du hyr med eget isolerat operativsystem, på hårdvara delad med andra kunder. |
