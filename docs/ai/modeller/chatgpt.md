# ChatGPT

ChatGPT är OpenAIs chattgränssnitt för GPT-modellerna. Det var det verktyg som lanserade AI-assistenter i bred allmänhet i november 2022. Det är i dag en av de mest använda AI-plattformarna.

## Versioner

| Modell | Styrka |
|--------|--------|
| GPT-4o | Snabb multimodal modell — text, bild och ljud |
| GPT-4 | Stark resoneringsförmåga |
| GPT-3.5 | Snabb och gratis — sämre på komplex kod |
| o1 / o3 | Specialiserade på matematik och logik |

## Komma igång

- **Webb:** chatgpt.com — gratis med GPT-3.5, betalt för GPT-4
- **API:** api.openai.com — betalt
- **GitHub Copilot:** AI i din IDE baserat på OpenAI

## Styrkor för programmerare

- Stor träningsdata — känner till nästan alla bibliotek
- Plugins och Custom GPTs — kan anpassas
- DALL-E-integration — kan generera bilder
- Bra på att debugga och förklara felmeddelanden
