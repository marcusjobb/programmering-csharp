# AI-modeller

Det finns flera stora AI-modeller och verktyg. Här är en översikt av de vanligaste — vad de är bra på, vad de kostar och hur de används av programmerare.

## Jämförelsetabell

| Modell/Verktyg | Tillverkare | Styrka | Gratis tier |
|----------------|-------------|--------|-------------|
| Claude | Anthropic | Lång kontext, noggrant resonemang, säkert | Ja |
| ChatGPT | OpenAI | Bred kunskap, plugins, image generation | Ja |
| Claude Code | Anthropic | Kodar direkt i din terminal/IDE | Nej |
| Gemini | Google | Integrerad med Google Workspace | Ja |
| Codex | OpenAI | Kodgenerering (nu integrerat i GPT-4) | Nej |

## Hur väljer man?

- **Skriva och förklara kod:** Claude eller ChatGPT fungerar bra
- **Jobba i terminalen:** Claude Code
- **Google-ekosystemet:** Gemini
- **API-anrop i applikation:** Anthropic API (Claude) eller OpenAI API

Alla stora modeller förbättras snabbt — kontrollera aktuella benchmarks vid val för produktionssystem.
