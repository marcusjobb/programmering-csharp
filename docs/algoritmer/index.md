# Algoritmer

Ett avsnitt om algoritmer som dyker upp om och om igen, oavsett vilken typ av applikation du bygger — sortera data, hitta kortaste vägen mellan två punkter, mäta hur lika två saker är, och fatta beslut baserat på flera villkor.

Sökalgoritmer (linjär och binär sökning) täcks redan under [Datastrukturer](../datastrukturer/sokalgoritmer.md) — den sidan gäller fortfarande, ingen anledning att upprepa den här.
