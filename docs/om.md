# Om C# boken

C# boken är ett öppet läromedel för kurser i C# och objektorienterad programmering vid Nion Education.

## Vad är det?

En Jekyll-baserad statisk webbplats som publiceras via GitHub Pages. Allt innehåll är skrivet i Markdown och versionshanterat med Git.

- **Repo:** [marcusjobb/programmering-csharp](https://github.com/marcusjobb/programmering-csharp)
- **Teknik:** Jekyll + Just the Docs
- **Språk:** Svenska (förklaringar), engelska (kod-identifierare)

## Bidra

Hittar du ett fel eller vill lägga till innehåll? Öppna ett issue eller en pull request på GitHub.

## Kodregel

Alla kodexempel i boken följer konventionen:

- **Identifierare** (variabelnamn, metodnamn, klassnamn) → **engelska**
- **Strängar och output** → **svenska**

```csharp
// Rätt
var greeting = "Hej världen!";
Console.WriteLine(greeting);

// Fel — åäö i identifierare ger fel färgning i syntaxhighlightern
var hälsning = "Hej världen!";
```
