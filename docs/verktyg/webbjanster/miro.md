# Miro

[Öppna Miro](https://miro.com/){: .btn }

Miro är en digital whiteboard för att skapa och dela idéer visuellt. Du kan rita flödesscheman, wireframes, mindmaps och backlog-boards — och samarbeta med andra i realtid på samma tavla.

Under kursen kan du använda Miro för att planera program innan du kodar, rita klassdiagram, eller visualisera hur olika delar av ett projekt hänger ihop.

Det finns även en mobilapp om du vill skissa idéer på språng, och ett presentationsläge som gör det enkelt att visa upp din planering för klassen.

Gratis att komma igång med.
