# Miro Board

[Öppna Miro Board](https://miro.com/){: .btn }

## Beskrivning

Miro är ett verktyg för att skapa och dela idéer. Man kan samarbeta på ett enkelt sätt med andra. Det är enkelt att skapa flera olika typer av innehåll, som t.ex. flödesscheman, wireframes, moodboards, mindmaps, backlog och mycket mer.

Det finns även en mobilapp som gör det enkelt att skriva anteckningar på språng.

En har presentationsläge så man kan ha det till att presentera skoluppgifter eller projekt.
