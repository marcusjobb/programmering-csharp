# Discord

[Installera Discord](https://discord.com/download){: .btn .btn-blue }

Discord används för kommunikation i kursen — snabba meddelanden, påminnelser och diskussioner mellan studerande och lärare.

## Kom igång

1. Ladda ner och installera Discord via knappen ovan
2. Skapa ett konto (eller logga in om du har ett)
3. Använd länken du fått av din lärare för att gå med i kursservern

## Tips

- Stäng av notiser för kanaler du inte behöver följa aktivt — högerklicka på en kanal → *Mute*
- Använd trådar (`Threads`) för att hålla diskussioner organiserade
- `@` + ett namn skickar en direktnotis till den personen
- Sök med `Ctrl+K` (snabbnavigering) eller `Ctrl+F` (sök i kanal)
