# Grafiska gränssnitt

Du har lärt dig C# genom att skriva konsolprogram. Det är rätt väg — konsolprogram är enkla och fokuserade på logiken.

Men C# används för mycket mer. Den här sektionen visar hur du bygger program med ett grafiskt gränssnitt: knappar, fönster, textrutor — det som brukar kallas GUI (Graphical User Interface).

## Tekniker i den här sektionen

| Teknik | Vad | Plattform |
|--------|-----|-----------|
| Windows Forms | Skrivbordsprogram med designern i Visual Studio | Windows |

## Vad du behöver kunna

Inget nytt. Dina kunskaper om klasser, metoder, List och Dictionary fungerar direkt i GUI-program. Det är bara ett nytt "skal" runt samma C#.
