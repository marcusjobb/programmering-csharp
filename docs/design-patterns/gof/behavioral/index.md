# Beteendemönster (Behavioral)

Den sista kategorin löser hur objekt **kommunicerar** och delar ansvar sinsemellan — hur en begäran vandrar genom systemet, hur objekt reagerar på varandras tillståndsförändringar, hur en algoritm görs utbytbar.
