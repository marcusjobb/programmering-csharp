# Strukturmönster (Structural)

Strukturmönster löser en annan fråga än de skapande: inte *hur* ett objekt skapas, utan **hur objekt och klasser sätts ihop till större strukturer** — utan att koppla ihop dem hårdare än nödvändigt.
